== Introduction

STM32 Groov register access, startup and linker code.

=== Dependencies

- https://intel.github.io/generic-register-operation-optimizer[Intel Generic Register Operation Optimizer]

=== Usage

You have this as subproject. Meson should know the target when configuring build. Following meson external properties should be set:
flash_origin
flash_kb
ram_origin
ram_kb
heap_size
stack_size
stm32_mcu
+ additional clock configuration.
